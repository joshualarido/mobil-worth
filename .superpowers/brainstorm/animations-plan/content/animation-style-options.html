Animation direction for MobilWorth

Pick the feel that best fits a clean, serious, presentation-ready ML demo.

A. Restrained CSS polish

Subtle fade/slide entrance, staggered panels, button spinner, confidence bar fill, and result-card reveal. No new dependencies.

B. More expressive CSS motion

Same dependency-free setup, but with more lift, shine on loading, stronger hover movement, and a more dramatic price reveal.

C. Framer Motion

Best for choreographed state transitions, but adds a dependency and is probably more than this lightweight demo needs.

Recommendation

Use A: restrained CSS polish. It fits the serious valuation-tool tone, keeps Vercel bundle size small, and gives the app enough movement to feel finished without becoming flashy.
